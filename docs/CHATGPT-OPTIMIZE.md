# 交給 ChatGPT 優化用的提示詞

把下面整段複製到 ChatGPT（建議使用可以讀檔或連 GitHub 的模型），並附上 `index.html`、`docs/DEVELOPMENT.md`、`docs/PROMPTS.md` 三個檔案。

## 一、整體健檢

```text
你是資深前端工程師兼教學設計專家。附件是一個給台灣中小學老師使用的單一 HTML 互動網站「AI 教育遊戲開發任務地圖」，
以及它的開發紀錄（DEVELOPMENT.md）和原始需求提示詞（PROMPTS.md）。

請先讀完三個檔案，再依下列面向檢查並提出優化建議：
1. 使用者體驗：老師與學生在手機、平板、電腦上的操作流暢度
2. 教學設計：10 個關卡的順序、檢核項目與提示詞是否合理、有無遺漏
3. 學術正確性：問卷量表的構面、題目與 APA 引用是否正確（請標出你不確定的部分，不要編造文獻）
4. 無障礙：對比、鍵盤操作、按鈕大小、螢幕閱讀器
5. 程式品質：可維護性、效能、錯誤處理

輸出格式：
- 用表格列出問題，欄位為：優先序（高／中／低）、面向、問題、建議做法
- 最後列出你建議優先處理的前 5 項
- 先不要改程式碼
```

## 二、指定修改

```text
請依照以下需求修改附件的 index.html：
【在這裡寫你要的修改，例如：讓遊戲類型可以選一個主類型加一個輔助類型】

規則：
1. 保持單一 HTML 檔，不要引入建置工具或框架
2. 不要改動 localStorage 鍵名 aiEduGame2 與資料格式，避免使用者遺失進度
3. 介面文字使用繁體中文（台灣用語）
4. 修改內容資料（遊戲類型、風格、量表、關卡）時，請改 GAMES、SUPER、STYLES、INST、STEPS 這些陣列，不要把內容寫死在 HTML
5. 給我完整的 index.html，並條列說明你改了哪些地方
```

## 三、新增量表或文獻

```text
我想在 index.html 的 INST 陣列新增一個量表：【量表名稱】，屬於【介面 UI/UX／認知／情意／技能／遊戲體驗／科技接受】類。
請依現有格式提供一筆完整資料：id、cat、name、purpose、who、when、scale、orig（原始文獻 APA 第 7 版）、recent（近 10 年驗證或回顧文獻 APA 第 7 版）、items（5–8 題，中英對照，依構面改編）。
只列出你能確定存在的文獻，並附 DOI；不確定的請直接說明，不要編造。
```

## 四、檢查文獻

```text

用表格列出：文獻、是否正確、需要修正的地方、你的依據。無法確認的請標示「需人工查證」。
【貼上網站「問卷評量」頁「複製所選文獻」的內容】
```
