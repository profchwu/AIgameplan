# 開發提示詞紀錄（原文）

這是開發「AI 教育遊戲開發任務地圖」時，我對 AI（Claude）下的每一則提示詞，依時間順序保留原文。可以整份交給 ChatGPT 或其他 AI，讓它了解需求是怎麼一步步演變的。

開發日期：2026-11-22 至 2026-11-23（台北時間）

---

## 第一階段：規劃學習單

**Prompt 1**

```text
規劃一個AI 教育遊戲開發的check list學習單。

1. 選擇單元、對象
2. 選擇遊戲類型
3. 規劃玩法
4. 規劃前後測評量/後台儲存
5. 規劃遊戲主視覺風格
6. 運用AI生成遊戲素材
7. 規劃發布平台 (github/netlify/sites?)

幫我規劃
```

**Prompt 2**

```text
分析是否還有不足之處?
遊戲類型要列出目前所有可用的遊戲類型、
遊戲風格要列出所有的遊戲風格
每一個步驟都要提供跟AI對話的prompt & 並且可以複製
```

**Prompt 3**

```text
要增加前後測問卷評量，要提供幾個常用的學術理論問券&引用來源&實際問題(中英對照)。Likert scale ，可以有不同的角度，例如專家判斷 UI/UX介面、或者學生的認知/情意/技能問卷/學習成效問卷
```
