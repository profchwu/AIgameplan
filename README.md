# AI 教育遊戲開發任務地圖

互動式 checklist 學習單，帶老師與學生用 10 個關卡規劃一個 AI 教育遊戲：

1. 選擇單元、對象
2. 選擇遊戲類型（92 種，含 RPG、射擊、3D 世界等）
3. 規劃玩法
4. 前後測評量與後台儲存
5. 問卷評量工具（介面、認知、情意、技能、遊戲體驗、科技接受；附 APA 文獻）
6. 遊戲主視覺風格（44 種）
7. 運用 AI 生成素材
8. 發布平台
9. 試玩測試與修正
10. 課堂實施與成效分析

每一關都有可複製的 AI 提示詞，會自動帶入你填寫的資料。填寫內容只存在使用者自己的瀏覽器。
